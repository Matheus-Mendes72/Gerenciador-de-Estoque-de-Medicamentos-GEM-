# GEM - Gestão de Estoque de Medicamentos

O GEM é um sistema desktop de gestão de estoque farmacêutico desenvolvido para o Hospital Municipal de Pedra Branca – CE. O sistema centraliza e automatiza o controle de medicamentos e insumos, substituindo controles manuais e planilhas por uma solução integrada de rastreamento de lotes, validades e movimentações.

---

## Visão do Produto

O GEM proporciona à equipe do hospital uma gestão de estoque organizada, ágil e confiável. O sistema permite registrar as movimentações e fornece alertas visuais sobre produtos próximos do vencimento, prevenindo perdas, reduzindo falhas no acompanhamento e aumentando o controle sobre os medicamentos armazenados.

---

## Meta do Produto

Desenvolver um sistema integrado para a farmácia hospitalar que automatize o controle de entradas, saídas, lotes e validades, permitindo o gerenciamento de medicamentos controlados e antibióticos. A meta é fornecer histórico de operações e alertas para eliminar a dependência de planilhas, reduzindo erros, desperdícios e retrabalho.

---

## Tecnologias Utilizadas

- **Backend:** Java
- **Interface Gráfica:** JavaFX
- **SGBD:** PostgreSQL
- **Containerização:** Docker
- **Testes e CI/CD:** GitHub Actions
